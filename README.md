# Urban Bites

Urban Bites is a modern, responsive restaurant website designed to provide customers with an elegant online dining experience.

## Live Website

https://urban-bites-l35h.netlify.app/

## Features

- Modern and responsive design
- Mobile-friendly navigation menu
- Restaurant introduction section
- Interactive food menu
- WhatsApp food ordering
- Food gallery
- Contact section
- Scroll reveal animations

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Preview

This project was designed and developed as part of my web development portfolio.

## Installation

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
